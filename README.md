🔬 Engineering Philosophy

Build systems, not demos.

I care about what happens after:

npm run dev

A system should eventually answer:

- How does it scale?
- How does it fail?
- How is it secured?
- How is it observed?
- How is state managed?
- How are background jobs handled?
- How are retries performed?
- How are agents controlled?
- How are models routed?
- How do we recover from failure?

Prefer explicit architecture

Clear boundaries + Typed interfaces + Validated inputs + Controlled side effects + Observable execution = Maintainable systems

AI should be engineered

An LLM by itself isn't an application.

A production AI system needs:

Model + Prompt/Context + Tools + Memory + State + Policies + Execution + Observability + Evaluation + Security

That's where I focus.
